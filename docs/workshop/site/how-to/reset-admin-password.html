Reset the admin password

Set a new password for the CSOC user admin when the old one is lost.

When you need this

When nobody knows the password of the CSOC user admin. The wizard does not store it, but it can set a new one through Keycloak.

Before you start

  • Open the wizard and resume the environment.

Steps

  1. Go to the Done step.
  2. In the Admin account panel, which shows the username and email, press Reset admin password…. It generates a new password.
  3. Copy the password into your password manager.
  4. Press Set this password.

Check it worked

You can sign in to portal.csoc.example.org as admin with the new password.

The wizard signs in to Keycloak's own administration account, whose login the bootstrap stored in AWS Secrets Manager, and sets the new password for admin in csoc-realm. Running the bootstrap again does not change the password.

If it fails

  • The panel shows an error: your address must be in the allowed addresses, because the wizard reaches Keycloak at auth.csoc.example.org. See Allow a new IP address.
