Request DNS delegation from your DNS administrators

Ask the people who manage your institution's domain to delegate a subdomain to the CSOC's AWS account.

When you need this

When central IT, not you, manages your institution's domain, for example example.org, and you need csoc.example.org delegated to the CSOC account. Requests at most universities take days, so start early.

Before you start

  • Ask central IT whether the subdomain is free and whether delegation to an AWS account is allowed. Some institutions require a security review or a named technical contact.
  • Complete Setup up to the zone, choosing I'll add the NS records myself under Delegate it from the parent zone using. After Set up zone and delegation, the box Add these records to the parent zone lists the four name servers.

Steps

  1. Copy the request below and replace the placeholders, including the four name servers from the box.
  2. Send it through your institution's DNS request process.
  3. While you wait, close the wizard; the zone and the bucket stay in your account. Use the time to finish the other prerequisites, have Security, cost and responsibilities reviewed, and ask your cloud administrators to confirm that the services the CSOC uses are allowed. The wizard cannot go past Setup until the delegation is in place.
  4. When central IT confirms, resume. The page continues by itself once it sees the zone.
text
Subject: DNS delegation request for <your-domain>

Hello,

We are setting up a Gen3 CSOC, a platform for deploying research data commons,
in an AWS account owned by <your-department>. Please delegate the subdomain
<your-domain> to our Amazon Route 53 hosted zone by adding one NS record set
for it, with these four name servers, in the <parent-domain> zone:

  <your-domain>.  NS  <name-server-1>
  <your-domain>.  NS  <name-server-2>
  <your-domain>.  NS  <name-server-3>
  <your-domain>.  NS  <name-server-4>

A TTL of 3600 seconds or less is fine.

We will create records only under <your-domain>, for example portal.<your-domain>,
auth.<your-domain> and one hostname per data commons. The zone also holds the DNS
validation records that AWS Certificate Manager uses to issue and renew TLS
certificates for those hostnames.

Technical contact: <your-name>, <your-email>
Account owner: <owner-name>, <owner-email>

Thank you.

Check it worked

Terminal dig NS csoc.example.org (with your subdomain) returns the four name servers, and the wizard shows Delegation is live and then Domain Verified.

If it fails

  • Central IT will not delegate subdomains: use Use DNS you manage yourself, or register a separate domain for the CSOC and host its zone in Route 53.
  • Red box Not delegated: the parent already uses this name: see Setup troubleshooting.
