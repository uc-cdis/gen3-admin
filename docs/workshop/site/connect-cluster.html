Connect the CSOC's cluster

Deploy an agent into the CSOC's own cluster, so that the CSOC can install commons there.

Where CSOC portalTime about 2 minutes

Goal

The CSOC installs commons through an agent in each cluster. Deploy the first agent, into the CSOC's own cluster.

Steps

  1. CSOC portal After you sign in, the portal opens its setup wizard, Welcome to CSOC. Press Get Started.
  2. On Configure Your Agent, Agent Name is filled in from the detected provider, which for the CSOC's cluster is aws. Keep it. You choose this name as the Cluster when you deploy a commons.
  3. Press Deploy Agent. The portal shows "Installing Agent" while the agent image downloads.
  4. Leave the setup wizard here: the remaining steps, labeled ArgoCD, Monitor and Alloy, install Argo CD, Grafana with Loki, and Alloy log collection, and a commons needs none of them. ArgoCD and Alloy have no skip button, so open https://portal.csoc.example.org/helm/gen3/deploy directly instead of continuing.

Done when: the portal shows "Resources applied to cluster" and the agent aws as connected.

Expected result

The portal lists the agent aws as a cluster.

Time

About 2 minutes from Deploy Agent until the agent shows as connected, including the image download.

What's happening

The CSOC does not connect to a cluster's Kubernetes API. Instead, each cluster runs an agent that connects out to the CSOC and keeps the connection open. Both sides prove their identity with certificates issued by the CSOC (mutual TLS), and the CSOC sends work, such as a Helm install, over that connection.

For the endpoint and the certificates, see Agents.

Troubleshooting

What you seeWhat it meansWhat to do
"Waiting for agent pod to start…" for more than 5 minutesA node is starting, or the agent image is still downloading through Squid.Press the retry button when it appears.
Connection Failed on the portal's Welcome pageThe portal cannot reach the CSOC API.Reload the page. If it persists, check that the CSOC API pod in the csoc namespace is running: kubectl -n csoc get pods.
The portal's labels differ from these docsThe portal image is newer or older than these docs.Follow the labels on screen; the sequence of steps is the same.
