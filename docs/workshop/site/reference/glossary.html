Glossary

The terms these docs and the wizard use, with links to their official documentation.

Terms

ACM
AWS Certificate Manager, which issues and renews the TLS certificates the load balancers serve. Docs.
ACM DNS validation
How ACM confirms that you control a hostname: it issues the certificate once it finds a DNS record it chose under that name, and renews it while the record stays. Docs.
Advanced and Advanced Options
Advanced is the fold under the run log that offers single operations (Init, Plan, Apply, Bootstrap, Finish install, Tear down…). Advanced Options is the fold on the Setup step with the Keycloak hostname, the VPC CIDR block and the commons data bucket.
Agent
A small service in each cluster that hosts commons. It connects out to the CSOC over mutual TLS and runs Helm and kubectl on the CSOC's behalf.
ALB
Application Load Balancer, the AWS load balancer that receives HTTPS traffic for the CSOC and for each commons. Docs.
Allowed addresses
The address ranges the CSOC's load balancers accept: the ranges in the Allowed addresses field on the Install step, plus the cluster's own outbound address. Also called the allowlist.
Alloy
Grafana Alloy, a collector of logs and metrics. The CSOC portal's optional Alloy setup step enables it in a cluster.
Argo CD
A GitOps tool that installs Kubernetes applications from a Git repository. The CSOC uses it when you choose With a GitOps repo; the wizard's labels spell it "ArgoCD". Docs.
Banner
The box under the wizard's stepper. It says where you stand and offers the next button to press. See Wizard states.
Bootstrap
The run that the Bootstrap CSOC button starts on the Install step. It stores the CSOC's secrets and installs the controllers, Keycloak and the CSOC portal.
Bootstrap wizard
The application at localhost:3000/bootstrap, running in Docker on your computer, that creates a CSOC in an empty AWS account and tears it down.
CA
Certificate authority, which issues certificates that others trust. The CSOC runs its own CA for agents' client certificates.
CIDR
A notation for an IP address range, such as 172.24.16.0/20 for the CSOC's VPC or x.x.x.x/32 for a single address on the allowlist.
CloudNativePG
A Kubernetes operator for PostgreSQL. It runs Keycloak's database. Docs.
Commons
Short for data commons: one Gen3 installation, deployed from the CSOC with the Helm chart gen3.
CSOC
The Gen3 Cloud Services Operations Center: a portal, its API and Keycloak in their own EKS cluster, from which you deploy and manage Gen3 commons. See What is a CSOC?
CTDS and uc-cdis
The Center for Translational Data Science at the University of Chicago develops Gen3 and the CSOC; uc-cdis is the GitHub organization where they are published. ctds.uchicago.edu.
Data commons
A shared platform where a research community stores, describes, finds and analyzes data, with access controlled per user and project.
Delegation
Four NS records in the parent zone that tell public DNS which name servers answer for your subdomain. Docs.
Direct or GitOps
The two ways to install the CSOC. Directly, from this wizard: the wizard installs with Helm. With a GitOps repo: Argo CD installs from a repository, and every change is a pull request.
Domain, zone, hostname
example.org is the parent domain. csoc.example.org is your subdomain, and its Route 53 hosted zone is "the zone". A hostname is one full name in it, such as portal.csoc.example.org.
Egress IP
The wizard's label for what these docs call the cluster's outbound address: the public IP address of the Squid instance that the cluster's traffic leaves through. It is added to the allowed addresses automatically.
EKS
Amazon Elastic Kubernetes Service, which runs the Kubernetes control plane. Docs.
Environment
One CSOC as the wizard records it in the state bucket, named by csoc-dev.
External Secrets Operator
A controller that copies values from AWS Secrets Manager into Kubernetes Secrets. Docs.
external-dns
A controller that publishes the hostnames of Kubernetes ingresses in Route 53. Here it writes only records it owns, only in the CSOC's zone. Docs.
Fargate
AWS Fargate runs containers without EC2 nodes that you manage. Here it runs Karpenter's controller, so that the cluster needs no fixed nodes.
Fence
Gen3's sign-in and authorization service. It signs users in through the CSOC's Keycloak, and with Arborist it applies the permissions in user.yaml. Repository.
Finish
The run that the Finish install button starts on the Install step. It completes the allowlist, waits for Keycloak and the portal, and creates the DNS records.
Gen3
Open-source software for building data commons. gen3.org; documentation.
Helm
The package manager for Kubernetes. The bootstrap installs the CSOC's components with Helm, and the agent installs each commons with it. Docs.
IRSA
IAM roles for service accounts: a Kubernetes service account is trusted by one IAM role, so its pods get only that role's AWS permissions, without keys. Docs.
Karpenter
A node autoscaler that starts and stops EC2 instances to fit pending pods. Here it runs on AWS Fargate, starts on-demand nodes of any instance family of generation 5 or newer, choosing the cheapest type that fits, and the cluster has no fixed nodes. Docs.
Keycloak
The open-source identity service that signs users in to the CSOC and, through it, to each commons. Docs.
Keycloak realm
A separate set of users, clients and settings in Keycloak. The CSOC uses csoc-realm, and each commons gets a client in it named fence-<namespace>.
KMS
AWS Key Management Service, which holds encryption keys. The CSOC's encrypted volumes, bucket and secrets use AWS managed keys; no customer managed key is created.
Load Balancer Controller
The AWS Load Balancer Controller, which creates load balancers for Kubernetes ingresses and services. Docs.
Lost run
A run whose end was not recorded, because the wizard's API restarted while it was in progress. The banner says its result is unknown and offers to retry it.
Mutual TLS
A TLS connection in which both sides present certificates, so each proves its identity to the other. Agents and the CSOC connect this way.
NAT gateway
An AWS service that lets resources in private subnets reach the internet without accepting connections from it. Docs.
NLB
Network Load Balancer, the AWS load balancer for TCP traffic. The CSOC's agent endpoint uses one, limited to the allowlist.
OIDC
OpenID Connect, the sign-in protocol between the portal, each commons' Fence and Keycloak. How it works.
Outbound address
The public IP address the cluster's traffic leaves from, which is that of the Squid instance in use. The wizard labels it "Egress IP".
Provision
The button on the Review step, and the wizard step that follows it. The button registers the environment and starts the init and the plan; the Apply button on the Provision step creates the infrastructure.
Registry
The records of each environment and its runs, kept in the state bucket. The banner is derived from them.
Runner
A container started for each run, with Terraform, Helm, kubectl and the AWS CLI.
Settled status
What the wizard believes exists in AWS, as recorded in the environment's record: new, planned, applied, bootstrapped, installed, partial or destroyed. It changes only when a run succeeds or leaves resources part-built. See Wizard states.
Squid
The outbound proxy. The cluster reaches the internet only through it, and only to listed destinations. squid-cache.org.
Terraform
The infrastructure-as-code tool that creates the network and the cluster from the gen3-terraform configuration. Docs.
user.yaml
A commons' permission file, which maps users' emails to what they may do. Guide.
VPC
Amazon Virtual Private Cloud, the private network the CSOC runs in. Docs.
