Where things live

Where the CSOC's state, secrets and records live in your AWS account and on your computer. Paths in the source code are on For developers.

In your AWS account

WhatWhere
State and registrys3://<state-bucket>/gen3-csoc/environments/csoc-dev/
SecretsAWS Secrets Manager, gen3-csoc/<csoc-name>/…
DNSRoute 53 hosted zone csoc.example.org
CertificatesACM in us-east-1
ClusterEKS in us-east-1, named csoc-dev

On your computer

WhatWhere
Run working directories~/.gen3-csoc/terraform
AWS profiles and the SSO cache~/.aws/config, ~/.aws/sso/cache
Developer settings.env in the repository (not committed). See For developers.
Timers and the theme choice for these docsYour browser's local storage
