Finish the install

Add the cluster's outbound address to the allowed addresses, wait for Keycloak and the portal, and point the hostnames at the load balancer.

Wizard step InstallTime 3–6 minutes

Goal

Press Finish install and wait until the banner says CSOC is ready.

Steps

  1. Press Finish install in the banner.
  2. Wait for === CSOC is installed === at the end of the log:
    log
    === CSOC is installed ===
Portal:   https://portal.csoc.example.org  (user: admin)
Keycloak: https://auth.csoc.example.org
  3. Wait for the banner CSOC is ready. Do not open portal.csoc.example.org in your browser before then: if your computer looks up the name before its record exists, your network's resolver can keep answering "no such name" after the record exists.

Done when: the banner reads CSOC is ready, "Sign in as admin with the password you set. DNS can take a few minutes.", with the buttons Open the CSOC and Tear down, and the wizard moves to the Done step.

Expected result

Finish install in progressWaiting for Keycloak and the portal, then creating the DNS records. 3–6 minutes.Buttons: [Stop this run]
CSOC installed; waiting for DNSThe records are in Route 53; public DNS usually answers within a minute or two. The portal link appears then. Opening it earlier can make your network remember that the name does not exist.
CSOC is readySign in as admin with the password you set. DNS can take a few minutes.Buttons: [Open the CSOC] [Tear down]

The wizard shows CSOC is ready only after its own check finds both hostnames in public DNS. "DNS can take a few minutes" refers to your own network's resolver, which can lag behind.

Time

3–6 minutes from Finish install to CSOC is ready; normal up to 12 minutes.

What's happening

The finish adds the cluster's outbound address to the allowed addresses, because the portal signs users in by calling Keycloak at its public hostname. It waits until Keycloak and the portal are running and the sign-in realm has been imported, and then removes the first administrator password from the cluster, so that only Keycloak holds it. Finally it creates two DNS records that point the CSOC's hostnames at the load balancer.

For the details, see What the finish does.

Troubleshooting

What you seeWhat it meansWhat to do
Banner: The finish failedThe environment is still bootstrapped. Finishing again is safe.Read the last lines of the log, then press Finish again. If the log points at the bootstrap, open Advanced and press Bootstrap.
Log: the ALB was not provisionedThe AWS Load Balancer Controller could not create the load balancer; the controller's log names the cause, for example the certificate or the subnets.The log line names the command to read the controller's log. Fix the cause it reports, then press Finish again.
Banner: CSOC installed; waiting for DNS for more than 10 minutesPublic DNS does not answer for the hostnames yet, or your network's resolver remembers an earlier "no such name" answer.Run dig portal.csoc.example.org (with your hostname). If it returns an address, switch your computer to a public resolver such as 1.1.1.1.
