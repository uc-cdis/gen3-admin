Review and provision

Check the configuration, then save it and compute a plan.

Wizard step ReviewTime about 1 minute

Goal

Confirm the configuration on the Review step, then press Provision. The Provision button saves your settings and computes a plan. Nothing is built until you press Apply.

Steps

  1. Read Review & Confirm. With the example values it reads:
    LineReads
    CSOC Namecsoc-dev
    Portalhttps://portal.csoc.example.org
    Keycloakhttps://auth.csoc.example.org
    Certificatechosen after the infrastructure is up (request, import or existing, on the Certificate step)
    DNSRoute 53 zone csoc.example.org
    Regionus-east-1
    AWS Accountyour account ID
    States3://gen3-csoc-csoc-dev-111122223333/gen3-csoc/environments/csoc-dev/
    VPC CIDR172.24.16.0/20
    Data bucketnone
    If a line is wrong, press Back and change it on Setup.
  2. Read the Rough Monthly Cost Estimate. Its badge shows $720–800/month: a us-east-1 figure before commons and data transfer, on Kubernetes 1.33, which is billed at the EKS extended-support rate. Cost breaks it down.
  3. Press Provision at the top right. The text below the cost reads "Provision registers csoc-dev in the state bucket and starts Terraform."

Done when: the stepper moves to Provision and the banner reads Init in progress.

Expected result

Init in progressDownloading the modules and providers. Under a minute.Buttons: [Stop this run]

The plan follows by itself. Continue with Plan.

What's happening

Provision writes a record for csoc-dev into the state bucket. Every banner the wizard shows from now on is derived from that record. Then Terraform prepares its working directory (terraform init) and computes the plan. A failed run never erases what was already done, so every failure can be retried from where it stopped. Wizard states lists every banner.

One run at a time

The wizard refuses to start a second run while one is in progress for the same environment, from any browser tab or computer.

Troubleshooting

What you seeWhat it meansWhat to do
Yellow box: Configuration Incomplete, with a listAn item on the Setup step is not confirmed: the identity, the bucket, the name, the hostname, or a Region with at least three availability zones.Press Back and fix the item listed.
Red box: Could not register the environmentWriting to the state bucket failed; the message names the cause, usually an expired sign-in.Sign in again, then press Provision again.
Banner: Nothing created yetThe environment is registered, but no plan has run.Press Plan in the banner.
