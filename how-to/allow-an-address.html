Allow a new IP address

Let a new network, such as a VPN or another campus, reach the CSOC portal and Keycloak.

When you need this

When the CSOC portal returns 403 Forbidden or refuses the connection from a network that worked before, or when a new team or campus needs access. Only the ranges in Allowed addresses can reach the CSOC portal, Keycloak and the agent endpoint.

Before you start

  • Find the range to add. For a single computer, it is its public IP address as a /32 range, for example 203.0.113.7/32; a site such as checkip.amazonaws.com shows the address. For a campus or VPN network, ask your network team for its outbound range, for example 198.51.100.0/24.
  • Terminal Sign in so that at least 15 minutes are left on your SSO sign-in.

Steps

  1. Open the wizard and resume the environment. Go to the Install step.
  2. Open Advanced under the run log (not Advanced Options on Setup) and press Bootstrap. The Install CSOC form opens again.
  3. Under Allowed addresses, add the range. Keep the existing ranges you still need.
  4. Type the same value of 12 or more characters in Admin password and Confirm admin password, or press Generate password. The form requires a password, but the existing admin password is not changed: the bootstrap sets it only when csoc-realm is first created.
  5. Press Bootstrap CSOC and wait for the banner Bootstrapped; ready to finish.
  6. Press Finish install and wait for CSOC is ready. The finish applies the new ranges.

Check it worked

From the new network, portal.csoc.example.org loads the sign-in page instead of returning 403 Forbidden. On the Install step, the summary lists the allowed addresses and the "Cluster egress IP".

If it fails

  • Still 403 from the new network: the range does not contain the address the network uses on the internet. Check it again at checkip.amazonaws.com from that network.
  • The bootstrap or the finish fails: see Bootstrap troubleshooting and Finish troubleshooting.
